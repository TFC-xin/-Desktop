# 有心Desktop

一款 Windows 桌面美化工具：可设置壁纸，并在桌面显示考试倒计时、水印和一言打字机。程序支持托盘运行、开机自启和单实例运行。

## 功能概览

- **壁纸**：选择图片文件夹，支持全屏铺满或原图居中；提供壁纸画廊。
- **桌面组件**：考试倒计时、水印和一言打字机，可调整位置或显示样式。
- **一言**：主页和桌面组件可分别配置请求分类与字数范围；网络请求失败时使用本地文案。
- **炫酷版特效**：倒计时、水印和桌面一言可分别使用跑马灯、呼吸灯或彩虹流动效果。
- **日常使用**：支持系统托盘、开机自启、单实例运行和功能自检。

## 安装与使用

1. 从上方发行版页面下载并解压压缩包。
2. 将程序解压到一个文件夹中；运行时请保持 `有心Desktop.exe` 与 `_internal` 文件夹位于同一目录（如压缩包包含该文件夹）。
3. 双击 `有心Desktop.exe` 启动，首次使用时在设置中选择壁纸文件夹并启用需要的桌面组件。
4. 关闭主窗口会将程序收至托盘；如需退出，请在托盘图标菜单中选择退出。

图片文件名中的数字可用于识别倒计时天数，例如 `273.jpg` 或 `高考倒计时100天.png`。

## 常见问题

**启动无反应或提示缺少 DLL？** 可能是安全软件隔离了程序文件。请确认压缩包完整解压，并检查安全软件的隔离记录；仅在确认文件来源可信后再恢复文件。

**桌面组件没有显示？** 在设置中检查对应组件的显示开关。

**如何备份设置？** 程序设置可能保存在 `config.json`，浮窗位置可能保存在 `state.json`。升级前请先备份程序目录中的配置文件；具体以所用版本实际生成的文件为准。
