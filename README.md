# 有心Desktop 发布说明

一款 Windows 桌面美化小工具：把喜欢的图片铺成壁纸，把考试倒计时、水印、一言打字机直接摆到桌面上。开机静默启动，不打扰、不遮挡。

---

## 一、两个版本怎么选

| 对比项 | 基础版（之前那版） | 炫酷版（本次发布） |
| --- | --- | --- |
| 定位 | 轻量、稳定、够用 | 完整功能 + 视觉特效 |
| 主页壁纸 + 打字机一言 | 有 | 有（重绘优化，拖动窗口不闪） |
| 壁纸设置 / 画廊 | 有 | 有 |
| 桌面倒计时浮窗 | 有 | 有（数字颜色可自定义） |
| 桌面水印 | 有 | 有 |
| 桌面一言打字机 | 有 | 有（字号、字体颜色可调） |
| 倒计时 / 水印 / 一言 动态特效 | 无 | 跑马灯、呼吸灯、彩虹流动 |
| 设置界面 | 单页平铺 | 每个功能一个独立页面 |
| 考试管理 / 功能自检 | 有 | 有 |
| 开机自启 / 托盘 / 单实例 | 有 | 有 |

简单说：**只想安静换壁纸、看倒计时，选基础版；想要动态文字特效和更顺手的设置页，选炫酷版。**

## 二、炫酷版功能

### 1. 主页
- 全屏美图背景，中间是打字机一句话，一条一条自然轮播
- 网络一言拉取失败时自动使用本地文案兜底，不会空着
- 窗口最小化或隐藏到托盘时自动暂停取词，恢复显示立即刷新

### 2. 壁纸
- 自选壁纸文件夹，图片放进去即可识别
- 两种显示方式：全屏铺满（拉伸）、原图居中（不拉伸）
- 「立即更换」一键换壁纸，「打开壁纸文件夹」直达目录
- 壁纸画廊：缩略图只加载屏幕内可见的部分，几百张也不卡；点一下即可切换

### 3. 桌面组件（沉在桌面层，不会挡住其他软件）
- **倒计时浮窗**：考试倒计时大字显示，数字颜色可自定义，可拖动、可固定、位置自动记忆
- **桌面水印**：`power by TFC`，背景颜色与位置可调
- **桌面一言打字机**：打字 → 停留 → 删除 → 换下一条，可自由缩放，字号、字体颜色可调，支持「立即更新」

### 4. 高级功能
倒计时数字、水印文字、桌面一言，三个组件可以分别设置文字动态效果：

- 无（纯色）
- 跑马灯（一道光带扫过）
- 呼吸灯（明暗渐变）
- 彩虹流动（色相循环）

### 5. 设置中心
按功能拆成独立页面，找东西不用翻长列表：

通用 / 桌面组件 / 一言请求参数 / 高级功能 / 主题 / 考试管理 / 功能自检

### 6. 一言请求参数
主页一言与桌面一言**分开配置**：分类（动画、漫画、文学、原创、网络、其他、影视、网易云、哲学）和最短/最长字数都能各自设置，互不影响。

### 7. 其他细节
- 全屏启动动画
- 关闭窗口进托盘，右键托盘可退出
- 开机自启可静默启动（不弹窗，直接进托盘）
- 单实例运行，不会重复开一堆
- 窗口固定 1000×680，布局不会错位

## 三、基础版功能

保留最核心的一套，界面更简单：

- 主页壁纸 + 打字机一言
- 壁纸文件夹设置、两种显示方式、壁纸画廊
- 桌面倒计时浮窗、水印、一言打字机
- 主题色切换、考试管理、功能自检
- 开机自启、托盘、单实例运行

差别只有一点：**没有动态文字特效，设置项是单页平铺的。**

## 四、安装与使用

1. 把压缩包解压到一个**空文件夹**
2. 确认 `有心Desktop.exe` 和 `_internal` 文件夹在同一层（缺一不可）
3. 双击 `有心Desktop.exe` 运行
4. 第一次打开先到「壁纸」页选择你的壁纸文件夹
5. 想要的东西没出现，去「设置 → 通用」勾选对应开关

> 图片文件名带数字可以自动识别为倒计时天数，例如 `273.jpg`、`高考倒计时100天.png`。

## 五、常见问题

**Q：双击没反应 / 提示缺少 dll？**
A：多半是杀毒软件（360、Defender）把 `_internal` 里的文件删了。把整个文件夹加入白名单，重新解压一次即可。

**Q：桌面组件不见了？**
A：设置 → 通用，把「显示浮动倒计时窗口」「显示桌面水印」「桌面显示一言」重新勾上。

**Q：桌面组件被其他窗口挡住了？**
A：它本来就设计在所有窗口之下、桌面之上，正常使用不会被挡；如果被系统恢复了层级，程序每 3 秒会自动压回桌面层。

**Q：换电脑后设置还在吗？**
A：设置保存在 `config.json`，浮窗位置在 `state.json`，升级时保留这两个文件和「壁纸」文件夹即可。

**Q：怎么彻底退出？**
A：关闭窗口只是进托盘，右键托盘图标选择退出。
